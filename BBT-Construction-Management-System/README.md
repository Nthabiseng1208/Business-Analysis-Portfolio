# BBT Group Construction Management System

## Project Overview

The BBT Group Construction Management System was a group project focused on analysing operational challenges within a construction organisation and proposing a centralised management solution.

The project examined challenges relating to project management, communication, financial management, resource management, progress tracking and system security.

## Business Analysis Focus

The analysis identified challenges in the existing construction management processes, including fragmented communication, difficulty tracking projects and resources, manual financial processes, limited progress visibility and security concerns.

The proposed solution aimed to centralise these activities within a construction management system.
